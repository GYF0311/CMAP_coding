# Module: i18n

## Purpose
Provide the P0 localized reading-layer scaffold and project locale config without changing canonical `.context` facts.

## Code Paths
- `src/commands/i18n.ts`
- `src/commands/config.ts`
- `src/i18n/context-mirror.ts`
- `src/i18n/config.ts`
- `src/i18n/locale.ts`

## Responsibilities
- Export `.context/i18n/<locale>/` scaffold mirrors for `MAP.md`, `STATUS.md`, `CHECKPOINT.md`, `DECISIONS.md`, `VERIFY.md`, and `modules/*.md`.
- Reject output directories that escape the project root or overlap canonical `.context` files.
- Preserve existing mirror files on repeated export so human/agent translations are not overwritten by scaffold regeneration.
- Write `TRANSLATION_RULES.md` that tells translation agents to translate prose only, preserve facts, preserve paths/commands/module ids/code identifiers/schema/operation names, keep frontmatter/relations unchanged, and never overwrite canonical `.context`.
- Check whether required i18n mirror files exist and return exit code 1 with missing paths when incomplete.
- Read and write `.context/config.yml` for `locale` and `fallback_locale`.
- Support `cmap init --auto --lang <locale>` by writing locale config while leaving canonical templates in English.

## Depends On
- `context` source files and module docs as canonical inputs.
- `cli` for command registration.

## Used By
- `cmap i18n export --lang zh-CN`
- `cmap i18n check --lang zh-CN`
- `cmap config set locale zh-CN|en`
- `cmap config get locale`
- `cmap init --auto --lang zh-CN|en`

## Data Flow
Commands read canonical `.context` files from the project root, write localized scaffold files under `.context/i18n/<locale>/` or an explicit `--out` directory, and keep `.context/config.yml` as deterministic project config.

## State / Storage
- `.context/i18n/<locale>/`
- `.context/config.yml`

## Constraints
- Do not call a model in P0.
- Do not write translated content into canonical `.context/*.md` or `.context/modules/*.md`.
- Do not let `--out` point at canonical `.context` itself.
- Do not overwrite existing localized mirror Markdown on scaffold export.
- Keep machine-readable identifiers stable in scaffold output.
- Supported locales are currently `en` and `zh-CN`.

## Tests / Verification
- `pnpm test tests/integration/m26-i18n-config.test.ts`
- `pnpm typecheck`

## When to Update This Doc
When adding locale support, changing config keys, changing i18n mirror coverage, or allowing translated content to flow into another review surface.
